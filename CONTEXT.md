# Screenshot Shelf

The Screenshot Shelf holds new screenshots until the user transfers, saves, or deletes them.

## Language

**Screenshot**:
An image of all or part of the screen.

**Widget**:
The small screen panel that holds pending screenshots.

**Capture folder**:
The separate folder where macOS writes new screenshots for the shelf.

**Pending screenshot**:
A screenshot held by the shelf that the user has not transferred, saved, or deleted.

**Selected screenshot**:
The pending screenshot shown in the widget preview.

**Save destination**:
The folder that the user selects for screenshots they want to keep.

**Save action**:
The user's command to keep the selected screenshot in the save destination.

**Discard action**:
The user's command to delete the selected pending screenshot.

**Idle period**:
The time since the last capture or widget action.
